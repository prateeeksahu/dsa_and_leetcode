Unlike constructors with many parameters, the Builder pattern allows you to create objects with various optional and required fields in a readable and flexible way.

> Removes compulsion to pass all paremeters in constructor
> dont need to override all the constructors 

> here builder class is created whose responsibilty is to take all parameters client want to pass .. rest will be assigned default values

> this class will also have a method that creates the object of main class

Key benefits:
	•	Simplifies object creation when many parameters are optional.
	•	Makes code more readable and maintainable.
	•	Avoids constructors with many parameters (the “telescoping constructor anti-pattern”).
	•	Can enforce immutability in objects. (by declaring varibales final and not making setters in the main class)
When to Use the Builder Pattern
	•	When you have a class with many parameters (especially some optional).
	•	When you want to make your object immutable.
	•	When you need a clear and organized way of object construction.

public class User {
    // Required parameters
    private final String username;
    private final String email;

    // Optional parameters
    private final int age;
    private final String address;

    // Private constructor
    private User(UserBuilder builder) {
        this.username = builder.username;
        this.email = builder.email;
        this.age = builder.age;
        this.address = builder.address;
    }

    // Static Builder Class
    public static class UserBuilder {
        // Required parameters
        private final String emailusername;
        private final String email;

        // Optional parameters - initialized to default values
        private int age = 0;
        private String address = "";

        public UserBuilder() {
        }

        public UserBuilder email(String email) {
            this.email = email;
            return this;
        }

        public UserBuilder username(String username) {
            this.username = username;
            return this;
        }

        public UserBuilder age(int age) {
            this.age = age;
            return this;
        }

        public UserBuilder address(String address) {
            this.address = address;
            return this;
        }

        public User build() {
            return new User(this);
        }
    }

    @Override
    public String toString() {
        return username + ", " + email + ", " + age + ", " + address;
    }
}


User user1 = new User.UserBuilder("alice", "alice@example.com")
                    .age(30)
                    .address("New York")
                    .build();

User user2 = new User.UserBuilder("bob", "bob@example.com")
                    .build();

System.out.println(user1);
System.out.println(user2);


Output : 

alice, alice@example.com, 30, New York
bob, bob@example.com, 0, 


 
> here user is the main class and builder is the class used to build the object step by step

> in builder class all the varibales required and initialized with either default values or null.
> then they are assigned values using setters in builder class 
> fianlly a build methdos calls constructor of main class and passes the object of bulder class with values assigned in it
> then this values are assigned to main class's object and it is returned in build() method which finally returns it to main 

> IMP 
  - the constructor of main class takes an input of builder class type
  - return type of setters is its own type (builder class) since while passing values while obj creation we need same obj to call next setter
  - build class creates the object

Advantages
	•	Readability: Easy to see which values are being set.
	•	Flexibility: Only set the parameters you need.
	•	Immutability: Finished object can be made immutable.
	•	Scalability: Easy to add more parameters in the future.
