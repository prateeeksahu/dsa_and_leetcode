NEW - this is when you have created the object of thread class but start is not called

	⬇

RUNNABLE - This is when the start method is called and thread is waiting for cpu to run it

	⬇

RUNNING - This state is when the thread is actually running (java has a funtion that tells the state of thread, in that expect this state it can display all the states)

	⬇

BLOCKED - this state is when thread is waiting to acquire a monitor lock to enter or re-enter a synchronized block/method

	⬇

WAITING - This state is when the thread is waiting for other thread to perform a task, no time limit

	⬇

TIME_WAITING - This state is when thread is waiting for other thread to perform a task, with time limit

	⬇

TERMINATED - This state is when the thread has completed the execution
