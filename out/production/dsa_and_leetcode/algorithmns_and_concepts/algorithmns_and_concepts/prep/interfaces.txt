Interfaces are again standard for classes to be defined

all methods defined in interface should be implemented in child class

All methods implemnrted in child must be made public

all variables declared in interface are final by default

we can implemant more than 1 interfaces but we can only extend one class - main diff between abstract class and interface

-----------------------------------------------------------

we can extend a class and implement multiple interfaces at same time 

> in interfaces static, default and private methods are allowed

> static methods will belong to interface only -  allowed because we can create object with interface reference 

> deffault methods were intorduced after java 8, these methods are methods with body in interface 

>these are helpful when you want to introduce a new method but if you do so you have to implemenmt it in all the classes implementing the interface, to avoid this we can create the interface and 
 use it in the class using it

> once defined with body in interface it can be used in class exteding it, the class can override it as well

> private methods can be used by extendong class, they are made for helping default methods for completeing their implementation
