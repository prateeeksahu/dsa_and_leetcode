> When we ask jvm to create map it creates an 16 sized array in heap memory (all objects are created in heap)

> once the bucket array is 75% filled the array is doubled.. this 75% is called loadfactor

> A bucket is a linked list that stores key value pair

> Key should be an object. JVM generates hashcode of the key and hashcode function is in object class.

> Now JVM finds bucket index by (hashcode & bucket.length - 1), whatever value will come is stored in that index bucket linked list

> Hash Collision -  if two keys has same hashcode or same bucket index then JVM first checks if there any same key is present, if yes then it replaces the key and value, if not present then adds a new element to linked list

> the get method in map works same manner as put does.. the diff is put adds a value and get reurns that value - O(n) retrival 

> whrn the bucket array linked list size crosses 8 the likned list is converted to red black tree or a balanced binary tree, in order to improve efficieny of retrival

> this 8 is called treeify threshold
