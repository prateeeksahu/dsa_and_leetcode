> Everything written in static belongs to class

> when we create new object a new copy of all methods and variables is created in that object, so all variables will have diff vaules

> when a variable is declared static it is shared among all the object, that means the value of this variable will always be same no matter from which object it is being accessed.

> since these variables belong to class we dont even need to create any object for them, we can access them using class name and variable seprated by . (dot)

> same goes for methods as well.

------------------------------------------------

why static can access other static contexts?

> Staic things work without objects while other non static things belongs to instancce, they cannot run without object

> other reason being only one copy of statc contexts exist, so it is easy to call a single method. But instance methods can be multiple since they belong to object
  this will confuse JVM which method to call so it allows only one method to call
