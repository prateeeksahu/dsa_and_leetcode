
This algorithm generates a topological order using BFS.

To achieve this, we maintain an array that tracks the in-degree (number of incoming edges) for each node.

We start by adding all nodes with an in-degree of 0 to the result. These nodes logically come first in the topological order because no other nodes lead to them, making them the starting points of the graph.

A queue is used to facilitate the BFS process. As we process nodes, we decrement the in-degree of their neighbors. If the in-degree of any neighbor becomes 0, it is added to the result and the queue, ensuring it appears in the topological order.

This approach ensures that nodes with no dependencies are processed first, allowing the graph traversal to progress logically.

class Solution {
    static ArrayList<Integer> topologicalSort(ArrayList<ArrayList<Integer>> adj) {
        ArrayList<Integer> a = new ArrayList();
        int[] ind = new int[adj.size()];
        Queue<Integer> q = new LinkedList();
        
        for(int u = 0 ; u<adj.size(); u++) for(int v : adj.get(u)) ind[v]++;
        for(int i = 0; i<ind.length; i++) if(ind[i] == 0) q.offer(i);
        
        while(!q.isEmpty()){
            int u = q.poll();
            a.add(u);
            
            for(int v : adj.get(u)){
                ind[v]--;
                if(ind[v] == 0) q.offer(v);
            }
        }
        
        return a;
  }
}
