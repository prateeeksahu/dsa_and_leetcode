there are mainly 4 types of functional interface inbuilt in java intorduced in java 8, they are :

1. Predicate - one input, returns boolean

	this interface has a method called test... it only returns boolean

2. Consumer - one input, no output

	this interface has a method called accept.. it doesnot return anything can be used to modify the data

3. Function - one input, one output - any datatype

	this interface also has accept method that takes 1 input and gives 1 output

4. Supplier - takes no input, gives one output

	this interface has method call get.. you can write any logic here .. it will return as per logic specifed


there are also biPredicate, biConsumer and bifunction which takes 2 parameters as input and return only one as output
