3. If a base class implements `Cloneable`, subclasses are expected to maintain cloneability, which is not always straightforward, especially with mutable fields or complex inheritance chains.
   
   If a class in the hierarchy does NOT support cloning, it can break the chain unexpectedly.

code -

class Address implements Cloneable {
    String city;
    Address(String city) { this.city = city; }
    public Object clone() throws CloneNotSupportedException {
        return super.clone(); // shallow copy
    }
}

class Person implements Cloneable {
    String name;
    Address address;
    Person(String name, Address address) {
        this.name = name;
        this.address = address;
    }
    public Object clone() throws CloneNotSupportedException {
        return super.clone(); // shallow copy
    }
}

public class Main {
    public static void main(String[] args) throws CloneNotSupportedException {
        Address addr1 = new Address("NYC");
        Person p1 = new Person("Alice", addr1);
        Person p2 = (Person) p1.clone();
        p2.address.city = "LA"; // changes address for p1 as well!
        System.out.println(p1.address.city); // Output: LA
    }
}
