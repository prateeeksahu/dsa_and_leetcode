| Feature                         | Abstract Class                                    | Interface (Java 8+)                                |
|---------------------------------|--------------------------------------------------|---------------------------------------------------|
| Keyword                         | abstract class                                   | interface                                          |
| Inheritance                     | Can extend only one abstract class              | Can implement multiple interfaces                  |
| Method Types                    | Abstract + concrete methods                      | - Abstract methods                                 |
|                                 |                                                  | - Default methods                                  |
|                                 |                                                  | - Static methods                                   |
| Variables                       | Can have instance variables (with any access modifier) | Only public static final constants                  |
| Constructors                    | Can have constructors                            | ❌ No constructors                                   |
| Access Modifiers                | Can use private, protected, etc.                | All methods are public by default                    |
| Multiple Inheritance Support     | ❌ Not supported (because Java does not allow multiple class inheritance) | ✅ Supported (via multiple interfaces)               |
| Use Case                        | Partial abstraction (common base class)        | Total abstraction (behavior contract)               |


Q: Can a class implement multiple interfaces?
A: ✅ Yes

Q: Can a class extend multiple abstract classes?
A: ❌ No — Java does not support multiple class inheritance

Q: Can an interface extend another interface?
A: ✅ Yes

Q: Can an interface extend an abstract class?
A: ❌ No — interfaces can only extend other interfaces
