Internal working

- list or arraylist can grow and shrink

- Internally they use array only

- when a list is created the inital size of internal array is 10

Adding an element

- first capacity is checked, if its not enough resizing os done

- for resizing new array of 1.5x capacity of previous array is created and elements are copied in it

- elements are stored like array, while adding new element it is added in last and while reading it reads like array arr[5]


Adding elements

- initial capacity is 10, elementData array can store 10 elements before resizing 

- growth factor is 1.5x, once array is full array increases by 1.5x

- copying the elements takes o(n) time

Removing the elements

- index bound is checked

- element is deleted and each element is shifted 1 left
