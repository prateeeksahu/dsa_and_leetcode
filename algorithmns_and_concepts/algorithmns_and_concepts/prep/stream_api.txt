> what is stream? - in simple terms is sequence of elements which we have got from a collection so that we can use declareative and functional programming

> why streamapi? - declaritive method (using stream) is more readable and consise than imperative method (loop based)
		 - we can do multiple operations in sigle line, reduces number of lines in code
		 - using parallel stream we can use multiple threads to do a task.. improves time 

		 ✅ Cleaner code (no boilerplate loops).
		 ✅ Functional style (map, filter, reduce).
		 ✅ Can process large data efficiently.
		 ✅ Parallel processing (parallelStream()).
		 ✅ Laziness – operations are executed only when needed.


A Stream pipeline always has 3 parts:
	1.Source → Collection, Array, I/O, or even infinite stream.

	2.Intermediate Operations (transformations, lazy).
		•Examples: map, filter, sorted, distinct, limit, skip.

	3.Terminal Operations (produce result, eager).
		•Examples: collect, forEach, reduce, count, min, max.

Intermediate operation are not performed until terminal operation is not invoked so even if you do some operation and store it in a list it wont store anything physcally until terminal method is called, this is called lazy evaluation

👉 Once a terminal operation is called, the stream is consumed and cannot be reused.



> How to create stream?

    - Stream<Integer> stream = listName.stream();
    - Stream<Integer> stream = Arrays.stream(arrayName);
    - Stream<Integer> stream = Stream.of(1, 2, 3); - makes a stream directly with no collection
    - Stream<Integer> stream = Stream.iterate(0, n -> n + 1).limit(100); - before limit it will generate infinite stream of n numbers, limit puts a size limit - funtional interface
    - Stream<Integer> stream = Stream.generate(() -> "hello").limit(100); - generate stream of hello - supplier interface

 - limit() is used to limit the number of elements in stream

 - filter(Predicate<T>) is to filter out elements, if they satisfy the condition then they are taken else filtered out

 - map(Function<T,R>) is used to perform the operation on all elements of stream

 - distinct() will remove all the duplicates

 - sorted() sorts the stream, comparater can also be passed

 - skip() will skip the first n elements specified

 - peek() is consumer that is generally used to print elements

 - max() sorts all elements and returns one element from one end based on condition/ comparater passed

 - get() will retrun the element 

 - count() return the count of elements

 -  reduce(identity, accumulator) - Reduces elements to one value.

🔹 What is Collectors?
	•	Collectors is a utility class in java.util.stream package.
	•	It provides static methods that return Collector objects, which are used with Streams to collect the result into different forms (lists, sets, maps, summaries, etc).
	•	Think of it as the final step of a Stream pipeline.

⸻

🔹 Commonly Used Collectors

1. toList()

List<String> names = Stream.of("A", "B", "C").collect(Collectors.toList());
// [A, B, C]


2. toSet()

Set<Integer> nums = Stream.of(1, 2, 2, 3).collect(Collectors.toSet());
// [1, 2, 3]

3. toMap()

Map<Integer, String> map = Stream.of("A", "BB", "CCC")
    .collect(Collectors.toMap(String::length, s -> s));
// {1=A, 2=BB, 3=CCC}


4. joining()

String result = Stream.of("Java", "Python", "C++")
                      .collect(Collectors.joining(", "));
// "Java, Python, C++"

5. counting()

long count = Stream.of(1, 2, 3, 4)
                   .collect(Collectors.counting());
// 4


6. summarizingInt() / summarizingDouble() / summarizingLong()

IntSummaryStatistics stats = Stream.of(10, 20, 30)
    .collect(Collectors.summarizingInt(Integer::intValue));
// count=3, sum=60, min=10, avg=20.0, max=30


7. groupingBy()

Map<Integer, List<String>> grouped = Stream.of("a", "bb", "ccc", "dd")
    .collect(Collectors.groupingBy(String::length));
// {1=[a], 2=[bb, dd], 3=[ccc]}


8. partitioningBy()

Map<Boolean, List<Integer>> partitioned = Stream.of(1, 2, 3, 4, 5)
    .collect(Collectors.partitioningBy(n -> n % 2 == 0));
// {false=[1, 3, 5], true=[2, 4]}


9. mapping()

List<Integer> lengths = Stream.of("Java", "C++", "Python")
    .collect(Collectors.mapping(String::length, Collectors.toList()));
// [4, 3, 6]
