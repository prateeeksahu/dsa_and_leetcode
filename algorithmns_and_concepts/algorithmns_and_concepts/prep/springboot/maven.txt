mvn install puts the jar in local in .m2 folder

mvn clean will remove everything from target folder


means:
	•	Run the clean lifecycle.
	•	The clean phase removes the target/ directory (or whatever output directory is configured).
	•	That directory contains all the compiled classes, packaged JAR/WAR files, temporary files, and anything generated during the last build.

⸻

Why is this useful?
	•	It ensures you start from a fresh build.
	•	Prevents issues where stale or outdated .class files, resources, or JARs cause weird errors.
	•	Often used before packaging or installing, like:

	mvn clean install

	which means wipe old build → compile everything → run tests → create and install the new JAR/WAR into your local Maven repo.
